
This command upgrades a release to a new version of a chart, or to new values.

The arguments are a release name and a chart reference (REPO/CHART). The new
release revision is computed from the chart defaults plus the values given on
this command line. Values from the previous revision are NOT carried over
unless you ask for them with --reuse-values:

    $ helm upgrade my-release myrepo/mychart --reuse-values --set replicas=2

Use --reset-values to start again from the chart's defaults. With --install
(-i), the release is installed if it does not exist yet, so the same command
works for the first deployment and for later changes.

Each upgrade creates a new revision; see them with 'helm history' and go back
with 'helm rollback'.

Usage:
  helm upgrade [RELEASE] [CHART] [flags]

Flags:
      --dry-run                  simulate an upgrade and print the computed values
  -h, --help                     help for upgrade
  -i, --install                  if a release by this name doesn't already exist, run an install
      --reset-values             when upgrading, reset the values to the ones built into the chart
      --reuse-values             when upgrading, reuse the last release's values and merge in any overrides from the command line
      --set stringArray          set values on the command line (can specify multiple or separate values with commas: key1=val1,key2=val2)
      --set-string stringArray   set STRING values on the command line (can specify multiple or separate values with commas: key1=val1,key2=val2)
      --timeout duration         time to wait for any individual Kubernetes operation (default 5m0s)
  -f, --values strings           specify values in a YAML file (can specify multiple)
      --version string           specify a version constraint for the chart version to use. If omitted, the latest version is used
      --wait                     wait until the release's pods are ready before returning

Global Flags:
      --kube-context string   name of the kubeconfig context to use
  -n, --namespace string      namespace scope for this request
