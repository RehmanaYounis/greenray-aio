kubectl controls the Kubernetes cluster manager.

 Find more information at: https://kubernetes.io/docs/reference/kubectl/

Basic Commands (Beginner):
  create          Create a resource from a file or from command-line arguments
  run             Start a single pod from an image

Basic Commands (Intermediate):
  get             Display one or many resources
  delete          Delete resources by file name, type and name, or label selector

Deploy Commands:
  rollout         Manage the rollout of a deployment or daemon set
  scale           Set a new replica count for a deployment

Cluster Management Commands:
  cluster-info    Display addresses of the control plane and cluster services
  cordon          Mark a node as unschedulable
  uncordon        Mark a node as schedulable
  drain           Cordon a node and evict its workloads in preparation for maintenance
  taint           Add, change or remove taints on one or more nodes

Troubleshooting and Debugging Commands:
  describe        Show detailed state of a resource, including recent events
  logs            Print the logs of a container in a pod
  exec            Run a command inside a running container

Advanced Commands:
  apply           Create or update resources from a manifest file or stdin
  patch           Update fields of a resource in place
  replace         Replace a resource from a manifest file (--force deletes and recreates)
  wait            Block until resources reach a given condition

Settings Commands:
  label           Add, change or remove labels on a resource
  annotate        Add or change annotations on a resource

Other Commands:
  api-resources   Print the resource types the server knows about
  version         Print client and server version information

Usage:
  kubectl [flags] [options]

Use "kubectl <command> --help" for more information about a given command.
Use -n/--namespace NAME with any command to work in a namespace other than "default".
