NAME
       slurm.conf - Slurm configuration file

DESCRIPTION
       slurm.conf lives on every node (here /etc/slurm/slurm.conf) and
       must be identical everywhere. slurmctld reads it at start-up and on
       scontrol reconfigure. On a Base Command Manager cluster the file is
       generated by CMDaemon from the Slurm configuration in cmsh (wlm
       mode): a hand edit lasts until the next regeneration.

PARAMETERS (the ones these labs use)
       NodeName=dgx-[01-04] CPUs=224 Sockets=2 CoresPerSocket=56
       ThreadsPerCore=2 RealMemory=2063000 Gres=gpu:h100:8 State=UNKNOWN
              One line per group of identical nodes. Gres names the GPUs;
              the type and count must match what slurmd detects from
              gres.conf, or the node registers as INVAL.

       PartitionName=defq Nodes=dgx-[01-04] Default=YES MaxTime=INFINITE
       State=UP [QOS=name] [AllowQos=...] [DefaultTime=...]
              One line per partition. Default=YES marks the partition jobs
              land in without -p; MaxTime bounds what a job may ask for.

       GresTypes=gpu
              Enables GPU scheduling; without it every Gres=gpu entry is
              ignored.

       SelectType=select/cons_tres
       SelectTypeParameters=CR_Core_Memory
              Consumable resources: cores and memory are allocated. A job
              without --mem gets the default below; with no default it
              takes the whole node's memory.

       DefMemPerCPU=8192
              Memory in MB given per allocated CPU to a job that names
              none. DefMemPerNode and DefMemPerGPU are the alternatives;
              set only one of the three.

       AccountingStorageEnforce=associations,limits,qos
              Which accounting rules slurmctld applies. Without "limits",
              QOS limits are stored but never enforced. Changing it needs
              a restart of slurmctld, not a reconfigure.

       HealthCheckProgram=/usr/sbin/nhc  HealthCheckInterval=300
              The node health check that drains nodes automatically.

       ReturnToService=0|1|2
              Whether a node that was DOWN comes back on its own when
              slurmd registers again.

       PriorityType=priority/multifactor and PriorityWeight*
              The job priority formula (sprio shows the factors).

RECONFIGURE OR RESTART
       Partition and node changes, limits and most scheduling parameters
       apply with scontrol reconfigure. AccountingStorage*, SelectType and
       plugin changes need slurmctld restarted.
